# Security Policy

## Scope

This policy covers the Lowground repository, its services and any official test infrastructure.

Lowground is an early-stage project. Do not use experimental rooms or deployments for sensitive conversations or production-critical work.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the contact method listed on the project maintainer's GitHub profile.

Include:

- a short description of the issue;
- affected component or URL;
- steps to reproduce;
- potential impact;
- a safe proof of concept, if available.

Do not open a public issue for an unpatched vulnerability. Do not include credentials, private room links or personal data in the report.

## Response

Reports will be acknowledged as soon as reasonably possible. The project will investigate, coordinate a fix and publish relevant information after the issue is understood and mitigated.

Please allow reasonable time for a fix before public disclosure.
